# Week 4 practice files

This is a small synthetic file tree for command-line practice. Nothing here describes real people, services, or system logs.

Do not edit this source copy during class. The instructor will give you a disposable copy so that mistakes are easy to undo.

## What is here

- `data/`: three small CSV files and five small JSON files for paths, globs, `find`, `head`, and line counts;
- `logs/`: three short logs with mixed capitalization for `grep`, pipes, and redirection;
- `docs/`: small Markdown files for copying, renaming, and Git recovery;
- `scripts/summarize_csv.py`: a supplied Python program that accepts one CSV path;
- `scripts/inspect_data.py`: a short script you will create in your disposable copy by moving familiar code out of a notebook cell.

The variety is intentional, but the contents are small enough to inspect directly. Files with spaces in their names are included so that quoting failures are visible and repairable.

Generated reports belong in `generated/`, which is ignored by Git.

Create `inspect_data.py` yourself during the lesson. It is intentionally not included here: the point is to type, save, run, edit, and rerun a small Python file.
