✓Before Friday’s quiz

  • Every format has parsing rules (quoting, escaping, nesting), and those rules are part of the data.
  • CSV and TSV carry no type information. Check dtypes after reading, and force string dtypes for identifier columns like case_id.
  • JSON distinguishes "0042" from 42, nests like Python lists and dictionaries, and has an explicit null.
  • XML nests with elements and attributes; absence can be an empty element or no element at all.
  • Missing values come in several forms (empty string, null, absent key), and flat formats collapse them into one.
  • Reconciliation means comparing row counts, missingness, and dtypes in the notebook, not eyeballing the files.
